# 说明性文件更新工作台 v1.20

本地批量 Word 更新工具。公开版保留完整通用源码、Web UI、批量处理逻辑和测试；不包含真实募集文件、说明性文件、验收材料或历史输出。

## 主要能力

批量导入与内容定位；来源内容到目标文档的结构化映射；整表替换；主标题、盖章页等保护区域隔离；自动处理与人工确认分流；保留目标文件结构、样式与修订。

## 安装与运行

```bash
pip install -r requirements.txt
python start.py
```

也可使用仓库内的 macOS/Windows 启动脚本。

## 测试

```bash
python -m pytest -q
```

当前公开候选回归基线：33 项通过，1 项因环境条件跳过。
